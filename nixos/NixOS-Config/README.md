# NixOS Config

## Structure

```
flake.nix               # Entry point — defines device configurations
configuration.nix       # Shared settings (printing, unfree, packages, etc.)
modules/                # Shared modules — enable per-device
hosts/
  <device>/
    default.nix         # Hostname + imports (shared config, hardware, modules)
    hardware-configuration.nix   # Auto-generated by nixos-generate-config
```

## Usage

### Rebuild a device

```bash
sudo nixos-rebuild switch --flake .#HP-Laptop
```

Replace `HP-Laptop` with your device name (folder name under `hosts/`).

### Add a new device

1. Generate hardware config:
   ```bash
   sudo nixos-generate-config --show-hardware-config > hosts/<name>/hardware-configuration.nix
   ```

2. Create `hosts/<name>/default.nix`:
   ```nix
   { ... }: {
     imports = [
       ../../configuration.nix
       ./hardware-configuration.nix
       ../../modules/boot.nix
       ../../modules/network.nix
       ../../modules/nix.nix
       ../../modules/user.nix
       # add only the modules this device needs
     ];
     networking.hostName = "<name>";
   }
   ```

3. Register it in `flake.nix`:
   ```nix
   nixosConfigurations = {
     HP-Laptop = mkHost "HP-Laptop";
     <name> = mkHost "<name>";
   };
   ```

4. Rebuild:
   ```bash
   sudo nixos-rebuild switch --flake .#<name>
   ```

### Update flake inputs

```bash
nix flake update
```

### Garbage collect

```bash
sudo nix-collect-garbage -d
```
